## 关于本分支 (About this fork)

本项目是基于 [voidtools/voidImageViewer](https://github.com/voidtools/voidImageViewer) 的汉化增强版本。

在此，首先要向原作者 **voidtools / David Carpenter** 表达最诚挚的感谢。`voidImageViewer` 是一款非常出色的轻量级看图软件，它秉承了与 Everything 相同的设计哲学——极致简洁、流畅高效。此次汉化与增强旨在让更多中文用户能够更方便、更舒适地使用这款优秀的工具。

### 改动说明 (Modifications)
相较于原版，此分支主要进行了以下改动：

*   **界面汉化 (UI Localization)**：完成了用户界面的中文本地化，包括菜单、对话框和提示信息。
*   **幻灯片切换动画 (Slideshow Transition Effect)**：为幻灯片放映模式增加了图片切换动画效果，在按设定时间自动切换时，过渡更加平滑流畅，提升了观看体验。
*   **完善中文文档 (Documentation)**：添加了中文版本的 `README` 和使用说明，以方便中文用户快速上手。
*  **鼠标悬停时显示界面**：当鼠标离开窗口时，自动隐藏标题栏、菜单、状态栏和工具栏，实现全屏沉浸式看图体验；鼠标移回时自动恢复所有 UI 元素。

其余核心功能和代码逻辑，均与原项目保持一致，未做任何修改。
# void Image Viewer
A lightweight image viewer for Windows with animated GIF/WEBP support.  
Opens and displays BMP, GIF, ICO, PNG, JPG, TIF and WEBP images as fast as possible.  
Animate GIF/WEBP files as accurately as possible.
