# RELEASE NOTES — voidImageViewer-i18n 3.7

发布日期：2026-11-18  
上一版本：3.6（2026-10-14）

## 一句话版本

3.7 在保持轻量、单文件、零运行时依赖的前提下，新增**最近打开 / 收藏夹**、**播放列表按名称筛选**、**图片信息面板（EXIF/GPS）** 三个实用模块，并对菜单、导航、配置与元数据读取做了一轮稳定性加固。

---

## 一、最近打开 / 收藏夹（新增）

- 文件菜单新增两个子菜单：**最近打开**、**收藏夹**；右键菜单同样可用。
- 最近打开：自动记录成功显示过的图片，最多 **20 条**，最新在前，重复路径自动去重并移到最前。
- 收藏夹：手动添加/移除当前图片，最多 **100 条**，支持“管理收藏夹”对话框（打开、移除、清空）。
- 存储继续使用单文件 `voidImageViewer.ini`：
  - `recent_count` / `recent_0..19`
  - `favorite_count` / `favorite_0..99`
- 路径按大小写不敏感去重；中文、空格、`&`、`=` 等特殊字符路径可正常保存和显示。
- 最近记录在退出时统一保存；收藏增删立即保存，避免崩溃丢收藏。
- 文件已不存在时：最近记录提示“文件未找到”并自动移除；收藏保留，方便移动硬盘重新接入。
- 菜单文本中的 `&` 已转义，避免文件名被当成菜单助记符。

## 二、播放列表按名称筛选（新增）

- 快捷键 `Alt+F` 呼出顶部浮动筛选条。
- 输入即筛选，默认匹配文件名子串，忽略大小写；输入含 `\`、`/`、`:` 时按完整路径匹配。
- 筛选条显示匹配数量；`Enter` 跳到下一个匹配，`Esc` 清空并关闭。
- 筛选只影响导航候选，**不删除、不重排播放列表**：
  - 上一张/下一张
  - 第一个/最后一个
  - 随机播放
  - 后台预加载
- **筛选结果为 0 时不会清空播放列表**，当前图片保持显示。
- 手动打开文件、打开文件夹、拖放文件时会自动清空筛选，避免新列表被旧条件过滤。
- Everything 随机模式下筛选不可用，会给出提示。

## 三、图片信息面板（新增）

- 快捷键 `Ctrl+I` 打开**无模态工具窗口**，打开后仍可继续翻图，信息自动刷新。
- 两列 ListView：项目 / 值，支持整行选择、滚动、复制。
- 信息分组：
  - **文件信息**：文件名、完整路径、大小、创建时间、修改时间
  - **图像信息**：格式、尺寸、位深、Alpha、DPI、帧数、当前帧、帧延时、总时长、估算解码内存
  - **EXIF**：相机厂商/型号、镜头、软件、拍摄时间、曝光、光圈、ISO、焦距、35mm 等效、曝光补偿、闪光灯、测光、白平衡、曝光程序、图像描述、作者、版权、EXIF 版本、色彩空间、方向
  - **GPS**：纬度、经度、海拔、方向
- EXIF 读取策略（B 方案）：Windows 属性系统优先，缺少核心字段时用 GDI+ 属性回退；读不到就明确显示“无 EXIF 数据”。
- “复制全部”/`Ctrl+C` 可把信息复制为文本。
- 记住窗口位置和大小；支持 RTL 布局与高 DPI。
- 对畸形 EXIF（NaN、无穷大、负数坐标、超大值）做钳制，避免未定义行为和错误显示。

## 四、3.7 期间修复的问题

- **“添加到收藏夹”一直灰色**：图片加载后只刷新了“最近打开”，没有刷新“收藏夹”；右键菜单弹出前也未强制刷新。现在图片加载、右键弹出、语言切换、空图/加载失败都会刷新菜单状态。
- **预加载激活时最近记录路径错误**：改用当前图片路径（current）优先、显示帧路径（frame）兜底，避免记录成上一张图。
- **筛选 0 匹配时清空播放列表**：`_viv_home` 在无候选时会调用 `_viv_blank()`；筛选激活时已拦截。
- **右键菜单命令执行时动态菜单不刷新**：菜单关闭后先清除 `_viv_in_popup_menu` 标志，再执行命令。
- **菜单文本/复制全部缓冲区越界风险**：修正 `string_cat` 对固定 1024 缓冲区的假设，菜单文本和复制内容改为有界追加。
- **阿拉伯语切回英语后仍是 RTL 镜像**：信息窗口和筛选条现在会同步设置/清除 `WS_EX_LAYOUTRTL`。
- **图片信息窗口出现在任务栏**：补充 `WS_EX_TOOLWINDOW`。
- **畸形 EXIF/GPS 数值**：增加 NaN、负值、超大值与数值类型判断，避免转 int 未定义。
- **死代码清理**：删除未使用全局变量、重复属性结构体、空状态控件、未使用参数；统一当前图片路径选择逻辑。

## 五、兼容性与已知限制

- 仍为纯 C + Win32、单文件 exe、`/MT` 静态 CRT，无新增运行时依赖。
- 支持 Windows 7 / 8 / 10 / 11，x86 与 x64。
- HEIC/HEIF 的 EXIF 仍取决于系统 HEIF 扩展或系统编解码器；无系统扩展时只能显示文件和图像基础信息。
- WebP 的 EXIF 同样取决于系统编解码器。
- 图片信息面板同步读取元数据；网络路径上可能短暂卡顿。
- 筛选计数每次输入全量统计；超大文件夹可能略有延迟。

- 可直接覆盖旧版 exe；`voidImageViewer.ini` 向后兼容，新增的 `recent_*`、`favorite_*`、`info_*` 键会自动写入。
- 旧版本会忽略这些新键，不会破坏配置。
- 建议首次测试前备份 `voidImageViewer.ini`。
