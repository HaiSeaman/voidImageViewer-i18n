# BB 文档包总览（净室开发素材）

> 本文档包是对一款 Windows 轻量级图片查看器（voidImageViewer 3.3，MIT 协议）做"功能与架构层面"分析后整理的**独立再开发素材**。
> 全部内容以功能描述、交互规格、架构思路的方式撰写，**不含任何原项目源码片段**。

## 一、文档包清单

| 文件 | 内容 | 用途 |
|---|---|---|
| `01-功能规格书.md` | 产品要"做成什么样"：功能清单、菜单树、快捷键、鼠标绑定、配置项、命令行、对话框、支持格式 | 给 AI 的需求输入 |
| `02-架构设计文档.md` | 技术选型、模块划分、线程模型、解码管线、渲染管线、配置与多语言架构、构建体系 | 给 AI 的蓝图 |
| `03-逻辑与实现方式详解.md` | 关键机制"怎么运作"：无边框窗口、自绘标题栏按钮、渲染与缩放、动画、幻灯片转场、预加载等 | 给 AI 的实现思路参考 |
| `04-AI开发提示词.md` | 给开发 AI 的完整任务书：角色、纪律、技术栈、10 阶段流程、验收格式 | 直接复制发给 AI |

## 二、净室开发（Clean-room）纪律——给主人和 AI 都要看的红线

本素材的合法前提是：**新代码只依据本素材编写，编写过程中不得查阅原项目源码**。请严格遵守：

1. **不要**把原项目任何源文件、代码片段喂给 AI；
2. **不要**让 AI"参考"原仓库的任何文件路径下的代码；
3. 本素材刻意不包含原代码文本，AI 依据它产出的代码属于独立表达；
4. 新作品必须**改名换图标**（软件名、图标、商标不能沿用）；
5. 完成后建议做一次"行为对比"验收：只比功能行为是否一致，不比代码文本是否相似。

## 三、原软件概况（一句话）

纯 C 语言 + Win32 API 的单文件 exe 图片查看器：无边框沉浸窗口、自绘标题栏按钮、GDI/GDI+ 渲染、四路解码（GDI+ / libwebp / WIC / libheif+libde265）支持 JPG/PNG/BMP/TIFF/ICO/GIF(动)/WebP(静+动)/HEIC/HEIF、10 国语言即时切换、Everything 搜索联动、幻灯片淡入淡出转场、便携 INI 配置。

目标平台：Windows 7 ~ 11（x86/x64），零运行时依赖（/MT 静态 CRT）。
