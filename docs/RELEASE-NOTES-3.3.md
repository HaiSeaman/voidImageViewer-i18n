# voidImageViewer v3.3 发布说明

- **发布日期**：2026 年 9 月 6 日
- **上一个版本**：v3.2
- **类型**：功能更新 + 深度加固版本（新增 2 项体验功能、修复 1 个真实 bug 与 3 个潜在缺陷、完成全仓库深度审计与依赖清理）

---

## 这个版本带来了什么？

v3.3 在 v3.2 的稳定性基础上，新增了两个高频使用场景的体验功能，并完成了一次覆盖全部源码、工程配置与依赖环境的深度审查——挖出并修复了 1 个会影响文件关联显示的真实 bug，清除了 25 个无效编译单元和一批仓库残留。

### 新功能一：左上角图片文件名（无边框模式）

- 在**窗口左上角靠边位置**实时显示当前图片的完整文件名（含扩展名）；
- 高度与右上角「最小化 / 最大化 / 关闭」自绘按钮**同一条带对齐**，颜色也使用按钮同款**白色**，字体采用系统标题栏字体，视觉完全融入；
- 文件名过长时自动显示省略号，绝不会顶到右侧按钮；
- **全屏时与按钮一起自动隐藏**，退出全屏立即恢复；
- 换图、删除、清空图片时名称实时跟随更新。

### 新功能二：ESC 键快捷关闭

- **全屏状态**按 ESC → 退出全屏（原有行为保持）；
- **非全屏状态**按 ESC → **直接关闭整个看图程序**；
- 正在拖动/缩放等操作时按 ESC → 仍是先取消当前操作（优先级最高）；
- 选项、重命名等对话框内的 ESC 行为不受影响。

### 最重要的修复：5 种文件类型的关联描述显示错乱

- **现象**：在「选项 → 关联」中勾选 .jpg / .png / .tif / .tiff / .webp 后，资源管理器中这些类型的"文件说明"会显示成 "English (US)"、"简体中文" 之类的语言菜单文字，而不是 "JPEG Image" 等正确描述。
- **根因**：界面文字的编号类型用的是 8 位无符号整数（BYTE，上限 255），而这批描述文字的编号已经排到了 256~260——存进 BYTE 时高位被**静默截断**成 0~4，恰好指向语言菜单的文字。
- **修复**：编号类型升级为 `int`，"无效"标记从 255 改为 -1；调试模式下的越界断言也随之恢复有效。

### 另外三个修复

1. **畸形动画 WebP 误报加载成功**：声明"0 帧"的动画文件之前会被当作加载成功（显示空白），现在正确判定为失败；
2. **WIC 解码缺少空流保护**：heif / webp 两个解码层都有空指针检查，唯独 WIC 层漏了，现已对齐；
3. **HEIC 方向解析的有符号左移未定义行为**：EXIF 方向字段解析改用无符号运算，消除 UB。

## 工程与依赖清理（全仓库深度审计）

- **删除 25 个无效编译文件**：libwebp 的 ARM/MIPS 平台加速代码（`*_neon.c`、`*_msa.c`、`*_mips*.c` 及配套头文件）在 Windows x86/x64 工程里编译出来是空壳——它们依赖的加速宏在本工程从未定义，纯白编译；
- **删除 ARM64 死配置**：工程里的 ARM64 配置链接的是 x64 的 HEIC 静态库，永远无法构建成功，已从 `.vcxproj` 与 `.sln` 中移除；
- **删除无用宏与残留**：`BZ_NO_STDIO`（项目根本没用 bzip2，且有一处重复定义）、`VIV_UINT64_MAX` / `VIV_DWORD_MAX` 死宏、viv.h 中注释掉的 include、误留在正常路径的调试打印；
- **二进制瘦身约 300KB**：10 张语言翻译表原来在每个源文件里都复制一份，现在改为全局唯一（extern 声明 + 单一定义）；
- **仓库卫生**：删除空目录 `.dsh-notes/`、残留的测试编译产物（`tests/*.exe/.obj`、`test_images/heif_dec_test.obj`）、冗余的第三方源码压缩包（`*.tar.gz`，源码树本身已在仓库中）；发布说明文档移至仓库根目录随代码一起维护；
- **构建脚本全面可移植**：4 个构建脚本（主构建、libde265 重建、单元测试、HEIC 调试工具）全部改用 `vswhere` 自动定位 Visual Studio、cmake 优先从 PATH 探测——换一台电脑不用再改路径；测试脚本同时纳入播放列表删除回归测试。

## 质量验证

- **构建**：x64 与 x86 双平台 Release 全量重编译通过，**零警告零错误**；Debug 配置同样通过；
- **单元测试**：左侧拖拽判定 16/16 用例通过；播放列表删除回归 3/3 通过（含故意复现旧 bug 的失败验证）；
- **全仓审计**：自动化扫描 0 死函数、0 死全局变量、0 未使用翻译条目（238 个翻译 ID 全部在用）、0 段注释掉的代码块；
- **版本信息**：双平台 exe 的 Windows 文件属性均为 3.3.0.0。
