## 1. 程序启动与生命周期

**为什么这样做**：看图软件的第一体验是"双击到出图"的速度，所以启动路径必须最短，且窗口直接以最终形态创建。

**做法**：
1. 初始化 OS 封装层（动态解析系统 API，兼容老系统）、初始化语言（先按配置，配置为自动则探测系统语言）。
2. 初始化默认快捷键表、预生成缩放系数表。
3. COM 单线程套间初始化、公共控件初始化、GDI+ 启动、加载线程同步锁初始化。
4. 读配置（exe 目录或 %APPDATA%）。
5. 先处理"安装类"命令行开关（关联注册等），命中即退出。
6. 单实例检查：命名互斥体已存在 → 找已有窗口（重试多次、每次间隔几十毫秒，防首实例窗口尚未注册的时序问题）→ 打包自己的命令行/目录/显示方式用 WM_COPYDATA 发过去 → 退出。
7. 注册窗口类（双击消息、垂直水平重绘风格），**直接以无边框样式创建窗口**（不要"先建有边框再拆"——会闪一帧边框）。
8. 允许低权限进程向自己发关窗消息（拖放与低权限互操作需要）；接受拖放文件。
9. 按 STARTUPINFO 的显示方式显示窗口（支持启动即最大化），再处理正常命令行打开文件。

**消息循环**：排空式（有消息就全取走，没消息就阻塞等待，绝不轮询空转）。每条消息先过**前置过滤器**：侧键消息按配置转译、键盘消息查自定义键表，被消费的不再分发。退出时：原子标志终止加载线程并等待其退出 → 保存配置 → 清缓存 → GDI+ 关闭 → COM 反初始化。

**风险与对策**：首实例窗口注册竞态 → 重试查找；加载线程持有 GDI 资源 → 必须先等线程死再清资源。

## 2. 无边框窗口与自绘标题栏按钮（UI 专章）

> 这是本软件 UI 的核心特色，规格：右上角三个自绘按钮（最小化 ─、最大化/还原 □、关闭 ×），顶部同高横条兼作拖动区，平时完全透明、悬停高亮、关闭钮悬停为红色——与系统标题栏观感一致。

### 2.1 窗口创建

- 窗口样式 = 弹出窗口（WS_POPUP）+ 裁剪子窗口兄弟标志；**不设**标题栏/系统菜单/粗边框。
- 兼容模式：配置可动态加回 标题栏|系统菜单|粗边框（用于"标准"界面预设），切换时改窗口样式位 + 按矩形补偿调整窗口位置 + 通知系统框架已变（SWP_FRAMECHANGED）。
- 最大化钳制：弹出窗口默认最大化会盖任务栏，须在 WM_GETMINMAXINFO 里把最大化尺寸/位置钳到**工作区**（扣除任务栏）。
- 最小窗口尺寸 ≥（状态栏+工具栏高度）之类下限，防 UI 崩坏。

### 2.2 按钮几何（展现层）

| 项目 | 规格 |
|---|---|
| 按钮尺寸 | 46×28 逻辑像素（宽×高）；横条高度=28 |
| 布局 | 右上角从右向左：关闭 → 最大化/还原 → 最小化 |
| 图标绘制 | 无图标资源，**运行时用画笔画线**手绘：×为两条对角线、─为横线、□为方框，约 10px 大小，白色 1px 线 |
| 最大化态 | 画"还原"双叠方框 |
| 常态背景 | **完全透明**（只画白色线条，不铺底色） |
| 悬停 | 灰色背景；**关闭按钮悬停为红色**(约 RGB 232,17,35，贴近系统) |
| 按下 | 更深的背景色 |
| 绘制时机 | 全部在 WM_PAINT 末尾、图片画完之后；用剪裁把绘制限制在按钮小矩形内，防止污染图片 |
| 局部刷新 | 状态变化时只使按钮区域失效并立即同步重绘（不等下一帧），保证手感 |

### 2.3 命中测试（交互层核心）

WM_NCHITTEST 处理顺序（重要）：
1. 先问自绘按钮：命中关闭→返回 HTCLOSE；最大化→HTMAXBUTTON；最小化→HTMINBUTTON。返回这些后，**按钮的按下/释放全由系统非客户区消息驱动**，自己不用管鼠标捕获。
2. 未命中按钮且无边框时：手工按系统边框宽度把四角/四边映射为 8 个方向命中值（HTLEFT/HTRIGHT/HTTOP/HTBOTTOM/HTTOPLEFT…）→ 无边框窗口也能拖边缩放。
3. 落在顶部横条（按钮除外）→ 返回 HTCAPTION → 系统原生支持拖动窗口、双击最大化、Aero Snap 全套免费获得。
4. 其余交给默认处理（客户区）。

### 2.4 按钮交互链（按下→执行）

- WM_NCLBUTTONDOWN（命中按钮）：记录"按下的是哪个钮"+ 重绘显示按下态。
- WM_NCLBUTTONUP：**只有在同一个按钮上释放**才执行（中途拖出=取消，与系统一致）；执行方式=向自己发 WM_SYSCOMMAND 的 SC_CLOSE/SC_MAXIMIZE(或 SC_RESTORE)/SC_MINIMIZE——最大化/还原逻辑全部复用系统命令。
- 悬停追踪：WM_NCMOUSEMOVE 里启动 TrackMouseEvent（非客户区离开通知）；收到离开消息清高亮。
- 兜底清态：窗口失活、捕获被抢走时清"按下"状态（防卡在按下态）。
- 双击顶部横条（非按钮区）：最大化/还原。

### 2.5 全屏与按钮条

- 全屏时按钮条与文件名**都隐藏**（全屏退出靠 Esc/快捷键）。
- 进入全屏：记录原窗口矩形与是否最大化 → 剥样式（标题栏/边框/菜单/状态栏）→ 移到所在显示器矩形 → **创建一个临时的弹出全屏假窗口并立即销毁**来把前台焦点推上去（否则任务栏可能不消失）。退出时反向恢复并补偿缩放级别差（全屏"铺满"与窗口"适应"两种填充语义的缩放差异）。

### 2.6 工具栏（可选显示）

- 可选显示一排小控件按钮，默认隐藏（沉浸模式不创建，省 GDI 句柄）。真实按钮序列（从左到右）：
  **上一张 → 下一张 →（分隔）→ 播放幻灯片 / 暂停幻灯片 →（分隔）→ 最佳适应 → 1:1**。
- 实现形态：rebar 容器 + 工具栏子控件；图标从资源装入图像列表（16px 基准，按 DPI 缩放）；按钮带本地化文字提示与气泡。
- RTL 时按钮顺序镜像；切语言时销毁重建（提示文字随语言变）。

### 2.7 主人验收清单（UI 专章）

- [ ] 无边框下四边可拖拽缩放
- [ ] 顶部横条拖动窗口、双击最大化、拖到屏幕边出现 Aero Snap
- [ ] 关闭钮悬停红色、拖出取消、点下执行
- [ ] 最大化窗口拖动横条=还原（系统行为）
- [ ] 最大化不盖任务栏
- [ ] 全屏进出后窗口矩形与缩放级别精确恢复
- [ ] RTL 语言下整窗镜像、按钮条到左上角
- [ ] 悬停显隐开启时：移开鼠标 UI 消失、回到窗口 UI 复现，且不影响右键/快捷键

### 2.8 悬停显隐 UI（可选特性）

- 配置开关 `hover_show_ui`（默认关）。开启时：鼠标移出窗口或静止时隐藏自绘按钮条/工具栏/状态栏等浮层；鼠标回到窗口内再显示。与"2 秒无操作隐藏光标"是两条独立机制，可同时生效。
- 实现思路：定时轮询鼠标位置（悬停探测定时器），位置在窗口内→显示，在窗口外→隐藏；隐藏只是不绘制浮层，不改变窗口本体与图片区域。

## 3. 左上角文件名显示

- WM_PAINT 末尾绘制：白色文字 + **系统标题栏字体**（从非客户区度量参数取），左对齐垂直居中单行，过长用省略号截断，右界=按钮区左缘减 8px。
- 全屏或按钮条禁用时隐藏；不响应鼠标（纯展示）。
- 与按钮条同一横条带，视觉上是一条统一的"自绘标题栏"。

## 4. 图像加载线程与帧交付

**流程**：
1. UI 请求加载（传文件描述 + 是否预载标记）。
2. 若已有加载线程在跑 → 原子置终止标志，等它死，把请求排队为"下一个"。
3. 新线程：以顺序读标志打开文件 → 取大小（>2GB 拒绝）→ 分配全局内存读入 → 包成 IStream（**零拷贝**：后面解码器直接锁内存用）。
4. 解码分派：GDI+ → libwebp → WIC → libheif 依次尝试；GDI+ 支持 ICM 色彩管理开关。
5. 每解出一帧：alpha 处理（半透明像素与背景色预混合，之后不再保留 alpha）→ RGBA 转 24bpp BGR → 生成 GDI 位图 → 应用 EXIF 方向旋转 → 预生成一级 mipmap。
6. 每帧经"应答队列 + 自定义消息"送 UI 线程：首帧应答携带宽高/总帧数/首帧位图；追加帧逐个送。
7. 读文件与帧循环里多点检查终止标志，1MB 分块读。

**GDI+ 细节**：从流加载图像 → 按时间维度选活动帧 → 画到兼容位图（最近邻、无平滑）；帧延时属性以安全方式提取（属性数据可能是坏的，越界防护 + 坏值兜底）。

**WIC 细节**：先回卷流指针（GDI+ 用过同一条流，指针停在文件尾）→ 让 WIC 自嗅探格式建解码器 → 只取第一帧 → 已是 32bpp BGRA 就直拷（跳过转换器），否则建格式转换器转 → **CopyPixels 失败必须当失败**（不能把未初始化缓冲交出去）→ BGRA 原地换序成 RGBA。alpha 判定用"黑名单"：已知不透明的格式才报无 alpha，其余一律报有（对不透明图无害、对漏判透明图保命）。

**libwebp 细节**：锁流内存零拷贝 → WebPGetFeatures 嗅探 → 静态图一步解码；动画用动画解码器逐帧取（每帧是合成后的整画布 RGBA + 时间戳），**帧延时=相邻时间戳差**；畸形 0 帧文件必须判为失败。

**libheif+libde265 细节**：读内存上下文 → 主图句柄 → 解码到 RGB 交错 RGBA → 逐行拷贝压平行距 → 交付。静态链接坑：需静态构建宏 + 手写对齐分配符号垫片（见 17 节）。

**应答协议**：完成/失败/首帧/追加帧四类；UI 收首帧才知道"这是什么图"。

## 5. 渲染与 Mipmap

见 02 文档第 5 节管线图。补充要点：

- **只重画可见区域**：从 PAINTSTRUCT 的 DC 取"系统剪裁区域"并拆成矩形列表（RTL 时镜像），滚动时不会整图重拉伸——这是滚动流畅的关键。
- **放大不整图拉伸**：GDI 拉伸不理会剪裁区会处理整张图（超大图时极慢），因此对放大的情况按"可见矩形 ⇆ 源矩形"映射，只把需要的源区段画到临时小位图再贴回。
- **缩小走 mipmap**：从链上选"渲染尺寸 ≥ 该级一半"的最高分辨率级作源，剩余倍率交给最终拉伸（永不超 2 倍）。
- **平滑开关**：缩小模式可选最近邻(丢点)或平滑(HALFTONE)；放大同理；HALFTONE 需要先设置画刷原点否则有偏移伪影。
- **超大图分块**：单次拉伸超出 GDI 32768 像素限制时按块（如 512px）分片拼接。
- **背景填充**：图片未覆盖的区域用纯色刷填（窗口/全屏两套颜色配置）；WM_ERASEBKGND 直接返回已处理，由自己统一画背景（防闪烁）。

## 6. 缩放体系与滚轮缩放

- 两套缩放量相乘（主缩放档位 × Pan&Scan 系数）得最终渲染尺寸；主缩放 0 档=适应窗口，最高档≈16 倍。
- **滚轮缩放算法（光标锚点）**：
  1. 换算光标相对图片渲染位置得到"图上坐标"；
  2. 改变缩放档位，得新旧渲染尺寸；
  3. 新图上坐标 = 旧图上坐标 × (新渲染/旧渲染)；
  4. 反推视图偏移使光标下的像素纹丝不动。
  无鼠标坐标时（菜单/热键触发）以视口中心为锚。
- 1:1 模式：进入保存旧档位、退出恢复；此时渲染尺寸=原图尺寸，滚动换算以原图尺寸为基准。
- 视图偏移统一经一个"设置视图"函数收敛：含钳制（小于视口强制居中；大于视口不露边；配置项控制）。

## 7. 平移拖拽（智能左键）

**决策纯函数**（输入四布尔，输出三选一，必须可独立单测）：

```
有平移余地 || 全屏 || 显示标题栏  →  平移图片
否则 最大化                      →  什么都不做
否则                            →  移动窗口
```

（"平移余地"= 渲染尺寸任一轴超过视口。）

**执行**：
- 平移：鼠标捕获 + 记录起点；WM_MOUSEMOVE 里按增量滚动视图（可选"平滑滚动"用 ScrollWindowEx 平移并只失效新露出的部分；RTL 有兼容问题时退回普通失效）。
- 移动窗口：**向自己发非客户区左键按下消息（HTCAPTION + 屏幕坐标）**——借系统拖动机制，免费获得贴边、双击等全部行为。
- 中键"抓手锁定"：捕获 + 隐藏光标 + 每次移动把光标 SetCursorPos 钉回按下的原点，用累计位移驱动滚动；左/中键抬起结束。
- Esc 取消进行中的拖拽（优先级最高）。

## 8. 动画播放计时

- **高精度定时**：优先用定时队列定时器（1ms 周期，回调里只投递一条普通定时消息防重入），系统不支持退回普通 SetTimer（最低精度约 15.6ms）。
- **时间推进**：用高精度性能计数器累计 tick；循环判断"当前帧延时÷速率 到点没有"，到点推进，一次 tick 可连推多帧（追帧），并记跳帧数。
- 帧延时：解码时已换算为毫秒；**任何 ≤0 的延时按最小值（如 1ms）兜底**——否则零延时帧会让推进循环永不休眠，UI 挂死。
- **加载中边界**：只在"已加载数"内循环/单步/后跳（防读到未初始化帧）；后跳不得回绕到 -1（钳到首帧）。
- 速率表：0.125x…8x 共 21 档，重置回 1x。
- 播放/暂停是纯标志位翻转 + 状态栏/菜单刷新。

## 9. 幻灯片与淡入淡出转场

- 幻灯片：普通定时器到点调"下一张"；启动时非全屏则先进全屏；每次换图重置定时器。
- 间隔：预设表（250ms…60000ms）单选 + 自定义对话框（毫秒/秒/分钟换算回 ms，下限钳 1）+ "动画时长"模式（取当前动画全部帧延时之和；未加载完时回退固定间隔）。
- **淡入淡出实现（不用分层窗口）**：
  1. 换图前：把当前窗口内容 BitBlt 抓成一张"旧屏快照"位图，记录起始时刻；
  2. WM_PAINT 正常画**新图**；
  3. 然后**把旧屏快照以恒定源透明度叠加**上去（GDI AlphaBlend，源常量 alpha 从 255 线性降到 0）——旧图淡出，视觉上即新图淡入；
  4. 15ms 周期定时器触发失效重绘；按流逝时间算 alpha；时长钳 50–2000ms；
  5. 结束释放快照与定时器；**中途再换图立即中止并清理**（防快照泄漏/叠加错图）。
- **防休眠双保险**：① 幻灯片或动画播放中拦截"关屏/屏保"系统命令；② 播放期间设置持续执行状态标志（显示+系统必需）。

## 10. 播放列表、导航与预加载

- 链表节点带文件属性 + **单调递增加入序号**（取自高精度计数器）——排序并列时的最终稳定依据。
- 建列表：命令行文件 / 文件夹枚举（白名单扩展名过滤）/ 拖放 / Everything 回执。
- 导航：链表上按比较器找"大于当前的最小项"（上一个反之），找不到回绕；无列表时对目录现场枚举。
- 比较器分派：名称（系统自然排序比较）/大小/修改/创建/路径，方向可反；并列时序号定序。
- **预加载下一张**：以预载标记调"下一张"逻辑，解码结果进预载数组；真翻页时：目标正好=预载文件 → 首帧已到就把当前图让位、预载数组接管（**零延迟**）；未到就挂起标记"加载完成后激活"。
- **缓存上一张**：当前图完整加载后帧数组整体移入"缓存数组"；往回翻直接激活。
- **随机删图的坑**（历史事故）：从链表删节点后移动后续指针，"元素个数"和"字节数"搞混会造成悬垂指针随机崩溃——新实现必须把这类移动封装成带元素大小参数的统一函数。

## 11. 菜单、右键菜单与快捷键机制

见 02 文档第 10 节架构。补充实现要点：

- 菜单文案 ID 用 int（用小类型会在超 255 条 ID 时静默截断成别的文案——历史事故）。
- "隐藏命令"（不出现在菜单、仅快捷键/配置可触发）：命令表加一个标志位，构建菜单时跳过即可。
- 命令执行统一走 WM_COMMAND 消息（右键菜单用 TrackPopupMenu 的返回值拿命令 ID 再回发）。
- 快捷键匹配在消息循环前置过滤器完成（不等窗口过程），组装当前修饰键+虚拟键码查表；长按重复由消息附加参数判断。
- 同键冲突：新键登记时从旧命令摘除（否则一个键触发两条命令）。
- 选项对话框里改键在**临时副本**上进行，点确定才提交：提交→重建菜单→存配置。

## 12. 多语言即时切换与 RTL

- 切语言四步：存配置 → 重建主菜单（新建菜单→SetMenu→销毁旧菜单）→ 刷新标题/状态栏/右键勾选 → 工具栏若显示则销毁重建。
- 对话框文本一律在 WM_INITDIALOG 注入，天然即时。
- 语言表是编译期常量数组，全部翻译单元共享**单一定义**（否则 exe 每个目标文件都塞一份、白白增大几百 KB）。
- RTL：主窗口创建时与切语言时动态加/去 RTL 布局扩展样式 + 通知框架重算 + 全量重绘；绘制坐标系统自动镜像（GDI 区域操作注意镜像后区域坐标要翻转）；对话框不做镜像。

## 14. EXIF 方向自动旋转

- 值域 1–8：2=水平镜像、3=180°、4=垂直镜像、5=转置、6=顺 90°、7=转置副、8=逆 90°；5–8 需**同时交换宽高**（否则布局横竖颠倒）。
- 常规格式：Shell 属性存储读照片方向属性（慢速文件用"尽力而为"打开标志；整段套结构化异常防护——属性存储对坏文件会抛异常）。
- HEIC：属性存储读不到，从文件内 Exif 块手写解析：块头 4 字节大端"到 TIFF 头偏移"（**必须无符号运算**，有符号左移高位是未定义行为）→ 校验 II/MM 字节序 + 魔数 42 → 取 IFD 偏移 → 遍历条目（每条 12 字节）找 274 号标签 → 按字节序读值。每步都查剩余长度。
- 应用时机：每帧解码后立即旋转；方向 5–8 时信息层报告的宽高也要对调。

## 15. 文件关联注册

见 01 规格书第 14 节。实现要点：
- 全程 HKCU 用户级（无需管理员）。
- ProgID 命名 = 程序名.扩展名；DefaultIcon 用 `"exe路径,0"`（.ico 文件用 %1 让文件自带图标）。
- 原关联默认值**备份到自定义值名**，卸载恢复；恢复失败也要保证 ProgID 整树删除（用能递归删树的 API，RegDeleteKey 删不掉带子键的键——历史事故）。
- "已关联"判定 = 两处值都等于期望值。
- 需要管理员的动作（装到 Program Files、开始菜单）：检测身份 → 不够就 runas 自我重启，重启时只透传**白名单**参数。

## 16. 配置持久化与单实例

- INI 解析：跳 BOM、单节、键二叉树；读按需 int/字符串。
- 双层配置：根 ini 的 appdata 键决定是否叠加 %APPDATA% 层；便携/安装切换由提权重启写回。
- **原子保存**：写 .tmp → MoveFileEx 替换；失败退 CopyFile。
- 保存时机：退出、会话结束消息（注销/关机）、选项确定、切语言、安装参数。
- 单实例：命名互斥体 + 查窗重试 + WM_COPYDATA 转交（数据=显示方式+完整命令行+当前目录）；500ms 时间窗内连续投递=追加播放列表。
