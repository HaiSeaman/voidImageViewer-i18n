# 01 功能规格书（净室开发需求输入）

> 本文档描述要开发的产品"应该长什么样、有哪些功能"。AI 编码时应以本文档为需求来源。

## 1. 产品定位

- 一款 Windows 桌面**轻量级、极速、单文件 exe** 的图片查看器。
- 设计哲学：启动毫秒级、内存占用低、默认无边框沉浸式、右键菜单为主操作入口。
- 支持平台：Windows 7/8/10/11，x86 与 x64 双架构。
- 分发形态：免安装绿色 zip + NSIS 安装包（中英双语）。

### 1.1 轻量与低资源占用要求（硬性需求，必须满足）

本软件的核心卖点之一是"资源占用低"，以下为**必须达成**的指标与手段，AI 实现时逐条对照：

| 维度 | 必须满足 | 具体手段 |
|---|---|---|
| 体积 | 单文件 exe，无任何运行时依赖 | 纯 C + Win32；/MT 静态 CRT；语言表/图标全部编译进 exe；不用框架、不用脚本引擎 |
| 启动速度 | 双击到出图毫秒级 | 启动路径最短化；无插件/无初始化开销；窗口直接以最终形态创建（不先建后拆） |
| 空闲 CPU | 近似 0% | 消息循环**阻塞等待**（无消息就睡，绝不轮询空转）；无后台常驻任务 |
| 渲染开销 | 大图平移缩放流畅 | 只重画可见区域；mipmap 逐级减半**懒生成**；放大时只拉伸可见源区段（不整图拉伸）；超大图分块拼接 |
| 内存 | 与"当前图+下一张"成正比，不随历史膨胀 | 运行期**不保留原始像素缓冲**（解码即转 GDI 位图，旋转除外）；边解码边播；预加载只缓存 1 张、上一张只缓存 1 张；帧用完即释放 |
| GDI 句柄 | 节制使用 | 状态栏/工具栏/菜单栏默认**不创建/不显示**（沉浸模式）；按钮条为纯绘制非控件 |
| 解码 | 不浪费内存 | 文件读入全局内存后**零拷贝**交给解码器；单条加载线程 |
| 本地化 | 不增加运行时负担 | 语言表编译进 exe，切换零加载开销 |

验收对照：任务管理器中空闲时内存与 CPU 占用应很低；快速连续翻 100 张大图内存不持续暴涨；滚动/缩放不卡顿。

## 2. 支持的图像格式与解码引擎

| 格式 | 扩展名 | 解码引擎 | 特性 |
|---|---|---|---|
| 常见标准格式 | .jpg .jpeg .png .bmp .tif .tiff .ico | GDI+（系统自带） | EXIF 自动旋转、Alpha 透明、色彩管理（ICM，可开关） |
| 动画 GIF | .gif | GDI+ 帧解码 | 逐帧播放、播放控制 |
| WebP | .webp | 内置 libwebp（静态链接） | 静态 + 多帧动画 |
| HEIC/HEIF | .heic .heif | 内置 libheif + libde265（静态链接）为主；若系统装有 HEIF 扩展，WIC 可先行解码成功 | 无需系统"HEIF 图像扩展"即可打开 iPhone 照片 |

- 明确**不支持**：AVIF、APNG、TGA、WMF/EMF、CUR/ANI。文件选择器和搜索过滤器中不得出现这些扩展名（避免"列得出、打不开"）。
- 全部图片扩展名白名单：`bmp gif heic heif ico jpeg jpg png tif tiff webp`（用于目录枚举过滤、打开对话框、Everything 过滤、文件关联，保持一处定义多处一致）。

## 3. 窗口与界面形态

### 3.1 三种界面预设（快捷键 1/2/3）
| 预设 | 标题栏 | 粗边框 | 菜单栏 | 状态栏 | 控件 |
|---|---|---|---|---|---|
| 极简（默认） | 隐藏 | 无 | 隐藏 | 隐藏 | 隐藏 |
| 紧凑 | 隐藏 | 有 | 隐藏 | 隐藏 | 隐藏 |
| 标准 | 显示 | 有 | 显示 | 显示 | 显示 |

> 注：紧凑预设只额外显示粗边框（可拖边缩放），其余元素仍隐藏——它并非"带全套界面的小窗口"。

### 3.2 无边框沉浸模式（默认）
- 窗口为纯客户区无边框窗口；右键呼出功能主菜单。
- 窗口右上角绘制**自绘按钮条**：最小化、最大化/还原、关闭（详见 03 文档 UI 专章）。
- 窗口左上角绘制**当前图片文件名**（白字、系统标题栏字体、过长省略号截断、不越过按钮区；全屏时隐藏）。
- 顶部按钮条同高的横条区域兼作**拖动窗口**的把手（命中测试返回标题栏语义）；无边框时四边可拖拽缩放窗口（手工返回 8 方向边缘命中）。
- 无边框窗口最大化时**不得覆盖任务栏**（需把最大化尺寸钳制到工作区）。
- 无边框最大化的窗口**不可被拖动**（防误拖还原）。

### 3.3 窗口行为
- 打开图片后窗口**自动贴合图片尺寸**消除白边（`fit_window_to_image`，默认开；保持纵横比时按比例贴合）。
- 两套独立的"窗口大小"机制（易混，务必分清）：
  1. **自动调整窗口**（`auto_zoom`，默认开；`auto_zoom_type`：0=按图片 50%、1=100%、2=200%）：加载新图时窗口自动缩放到图片像素尺寸的对应比例；
  2. **视图 → 窗口大小子菜单**（Alt+1=图片的 50%、Alt+2=100%、Alt+3=200%、Alt+4=自动适配）：手动执行同样操作；其中**自动适配=所在显示器尺寸的 3/5**（比例由 auto_fit_wide_mul/div、auto_fit_high_mul/div 控制，默认 3/5）。窗口初始尺寸（首次运行无配置时）也按屏幕 3/5 计算并在鼠标所在显示器居中。
- 记住窗口位置/大小/最大化状态到配置文件。
- 全屏切换（默认快捷键 **Alt+Enter**，或用右键菜单；注意默认键表中**没有 F**）：保存原窗口矩形，铺满所在显示器；退出时恢复；全屏隐藏按钮条与文件名；进入全屏需把前台焦点"推"上去（否则任务栏可能不消失）。
- 置顶三选一：从不 / 总是 / 播放幻灯片或动画时。
- 2 秒无操作自动隐藏鼠标光标（可关）。

## 4. 看图与缩放

### 4.1 缩放体系
- **主缩放**：约 16 档缩放级别，从"适应窗口"到最大 16 倍放大，指数式曲线（细档密、大档疏）。
- **1:1 原始大小**（默认打开图片即 1:1；Ctrl+Alt+0 或滚轮/菜单切换，再按一次恢复之前的缩放级别）。
- **Pan&Scan 微调**：小键盘 9/1 放大缩小、6/4 加宽减宽、8/2 增高减高、Num5 重置；Ctrl+小键盘 8/2/4/6/7/9/1/3/5 八方向移动与居中。
- 缩放开关项：保持纵横比（默认开）、填充窗口（窗口/全屏两套，默认开）、允许缩小到原图以下（默认开）。
- **以鼠标位置为锚点缩放**：滚轮缩放时，光标下的图像像素保持不动。
- 两个缩放过滤器可配：缩小（最近邻/HALFTONE 平滑，默认平滑）、放大（最近邻/HALFTONE，默认最近邻）。

### 4.2 渲染质量
- **Mipmap 多级缩放缓存**：对缩小的图预生成逐级减半的缩放链（懒生成、缓存到帧上），保证缩小时先降到最接近的级别再最终拉伸，消除锯齿并提速；旋转图片后缓存作废。
- 超大图支持：单帧渲染尺寸超过 GDI 单次拉伸上限时分块拼接绘制；像素缓冲分配前做溢出安全检查。

### 4.3 拖拽平移（智能左键）
判定规则（重要，需按此实现）：
1. 图片渲染尺寸超出视口（有平移余地）、或处于全屏、或显示标题栏 → **左键拖动=平移图片**；
2. 否则若为无边框普通窗口 → **左键拖动=移动窗口**（借系统标题栏拖动机制）；
3. 最大化窗口 → **什么都不做**。

其他平移方式：中键按住拖动（"抓手锁定"模式：按下后隐藏光标并钉住，拖动方向由光标相对原点位移决定）。

## 5. 动画播放（GIF / 动画 WebP）

- 播放/暂停（Ctrl+Space）、下一帧/上一帧（Ctrl+→/←）、首帧/末帧（Ctrl+Home/End）。
- 前后跳转三档步长（短/中/长，默认 500/1000/2000 ms，可配）。
- 播放速率：减慢/加快/重置，共 21 档（0.125x ~ 8x，1x 居中）。
- **边加载边播**：帧未全部解码完成时，只在已加载帧内循环等待。
- 帧延时健壮性：延时为 0 的帧按最小值兜底；缺延时属性的多帧图（多页 TIFF/多帧 ICO）不得崩溃。
- 动画完整循环至少播放一次后再翻页（可配，配合幻灯片）。

## 6. 幻灯片

- 播放/暂停（Space），启动幻灯片时若非全屏则自动进入全屏。
- 间隔预设：250ms、500ms、1s、2s、…、10s、20s、30s、40s、50s、1min（默认 5s）；可自定义（毫秒/秒/分钟三种单位输入）。
- "动画时长"模式：以当前动画自身整轮循环时长作为幻灯片间隔。
- **淡入淡出转场**（默认开，可关；时长可配 50–2000ms，默认 300ms）：切换时抓取旧画面快照，在新图上以线性递减的透明度叠加旧图，实现旧图淡出/新图淡入，由约 15ms 周期的定时器驱动重绘；中途换图立即中止并清理。
- **防休眠**：幻灯片或动画播放期间阻止屏保与显示器休眠（双重手段：拦截屏保系统命令 + 持续性执行状态标志）。

## 7. 导航与播放列表

- 播放列表来源：命令行多文件、打开文件夹（按扩展名白名单枚举）、拖放文件/文件夹、Everything 搜索结果。
- 排序（导航时实时比较，不物理重排列表）：文件名 / 文件大小 / 修改时间 / 创建时间 / 完整路径；升序/降序（默认：修改时间降序）；文件名用**自然排序**（数字按数值比较，Windows 7+ 用系统区域字符串比较的数字感知标志）；同值按加入列表顺序稳定排序。
- 上一张/下一张（←/→/PgUp/PgDn）、第一个/最后一个（Home/End）、随机模式（勾选）。
- 跳到对话框（J）：按名称搜索定位。
- **预加载下一张**（默认开）：后台预先解码列表中下一张，翻页时零延迟切换。
- **缓存上一张**（默认开）：当前图完整加载后保留在内存，往回翻直接使用不再读盘。
- 无播放列表时：对当前文件所在目录现场枚举来导航。

## 8. Everything 集成（可选功能）

- 通过窗口消息 + WM_COPYDATA 与 Everything 搜索工具通信（需 Everything 1.4.1+）。
- 三种用法：
  1. 打开搜索：`Ctrl+E` 输入关键词，结果（强制限定图片扩展名）替换当前播放列表；
  2. 追加搜索：结果追加进当前播放列表；
  3. 随机模式：从全部结果中随机取一张打开（用随机偏移的单条结果请求实现，越界自动重试）。
- Everything 未运行时给出友好提示。
- 收到外部进程发来的数据必须做**边界校验**（长度、偏移、容量），防恶意/畸形数据导致崩溃。

## 10. UI 组件规格

### 10.1 菜单系统
- **全部由代码动态生成**（不是资源文件菜单）：一张"命令表"定义所有命令（本地化文案 ID + 菜单标志 + 命令 ID），遍历生成主菜单栏。
- 每个菜单项自动追加 `\t快捷键` 显示；勾选/单选状态**每次弹出前重算**（不持久缓存）。
- 菜单结构（8 个一级菜单）：文件、编辑、视图、幻灯片、动画、导航、帮助 + 视图下多个子菜单（界面预设/窗口大小/Pan&Scan/缩放/置顶/语言/切换效果）。
- **右键菜单 = 常用命令 + 完整主菜单树拼合**：右键菜单本身是独立新建的弹出菜单（每次用完销毁），并把主菜单的各一级子菜单挂接进去以提供全部功能；销毁前须先把共享子菜单摘下，避免递归销毁。
- 单选组：置顶（3 选 1）、切换效果（无/淡入）、语言（10 选 1）、幻灯片间隔（预设+自定义+动画时长）、排序（5 选 1）+ 升/降序。
- 无图时禁用相关命令（删除、复制、打印等）。

### 10.2 完整菜单树与默认快捷键

**文件**：打开文件(Ctrl+O)、打开文件夹(Ctrl+B)、打开 Everything 搜索(Ctrl+E，隐藏项)、添加文件(Ctrl+Shift+O，隐藏)、添加文件夹(Ctrl+Shift+B，隐藏)、添加 Everything 搜索(Ctrl+Shift+E，隐藏)、─、打开文件位置(Ctrl+Enter)、编辑、预览、打印(Ctrl+P)、设为桌面壁纸、关闭(Ctrl+W)、─、删除(Del)、删除(回收站)(隐藏)、删除(永久)(隐藏)、重命名(F2)、属性、─、退出(Ctrl+Q)

**编辑**：剪切(Ctrl+X)、复制(Ctrl+C)、复制文件名(Ctrl+Shift+C，隐藏)、复制图像、粘贴(Ctrl+V，隐藏)、─、顺时针旋转、逆时针旋转、─、复制到文件夹、移动到文件夹

**视图**：标题栏(隐藏)、边框(隐藏)、菜单栏、状态栏、控件（以上勾选型）、界面预设▸(1=极简 2=紧凑 3=标准)、─、全屏(Alt+Enter)、幻灯片(F11)、窗口大小▸(Alt+1=50% Alt+2=100% Alt+3=200% Alt+4=自动)、刷新(F5)、─、允许缩小、保持宽高比、填充窗口、1:1(Ctrl+Alt+0)、最佳适配(隐藏)、─、平移与扫描▸(Num9/1/6/4/8/2 + Ctrl+Num5/8/2/4/6/7/9/1/3 + Num5 重置)、缩放▸(+/- 放大缩小，小键盘与 Ctrl 组合同义，Ctrl+0 重置)、─、置顶▸(总是=Ctrl+T/播放或动画时/从不，单选)、选项(O)、语言▸(单选 10 项)、切换效果▸(无/淡入，单选 + 切换时长)

**幻灯片**：播放/暂停(Space)、─、间隔▸(减慢=↓ 加快=↑；250ms…1min 单选；自定义…；动画自身时长)

**动画**：播放/暂停(Ctrl+Space)、─、前跳中(Ctrl+PgDn)/后跳中(Ctrl+PgUp)、短/长前后跳(隐藏)、─、下一帧(Ctrl+→)/上一帧(Ctrl+←)/首帧(Ctrl+Home)/末帧(Ctrl+End)、─、减慢(Ctrl+↓)/加快(Ctrl+↑)/重置(Ctrl+R)

**导航**：下一张(→/PgDn)、上一张(←/PgUp)、─、第一个(Home)、最后一个(End)、─、排序▸(名称/完整路径/大小/修改日期(**默认**)/创建日期 单选 + 升序/降序 单选)、随机(勾选)、─、跳到(J)

**帮助**：帮助(F1)、命令行选项、─、主页、捐赠、─、关于(Ctrl+F1)

**硬编码键**：Esc=取消当前拖拽 > 退出全屏（并暂停幻灯片）> 退出程序；左键双击=切换全屏（当左键动作为滚动类时）。

### 10.3 鼠标绑定（可配置）
| 输入 | 配置键 | 默认 | 可选值 |
|---|---|---|---|
| 左键 | left_click_action | 拖动滚动 | 拖动滚动/播放暂停幻灯片/播放暂停动画/放大/下一张/1:1 拖动/滚动或拖窗口 |
| 右键 | right_click_action | 上下文菜单 | 菜单/缩小/上一张 |
| 滚轮 | mouse_wheel_action | 缩放 | 缩放/上滚下一张/上滚上一张 |
| Ctrl+滚轮 | ctrl_mouse_wheel_action | 缩放 | 同上 |
| 侧键 X1/X2 | xbutton_action | 翻页 | 缩放（X1 放大 X2 缩小）/翻页 |

- 另有 `hover_show_ui`（默认关）：开启后 UI 元素（自绘按钮条/工具栏/状态栏等）仅在鼠标悬停时显示、移开自动隐藏；同时存在 2 秒无操作自动隐藏光标的独立机制。

### 10.4 快捷键自定义
- 选项对话框内：命令列表 + 按键列表 + 添加/编辑/删除。
- 录制控件实时捕获按键（忽略单独的修饰键），显示"此键已被某命令使用"的冲突提示；保存时自动从旧命令上摘除冲突键。
- 同一命令可绑定多个键；键值 = 虚拟键码 + Ctrl/Shift/Alt 修饰位。
- 配置文件中每个命令一行，键名由**英文**菜单路径派生（跨语言稳定），值为逗号分隔的十进制键值列表。

### 10.5 状态栏（默认隐藏）
| 段 | 内容 | 条件 |
|---|---|---|
| 主段 | 状态文字：临时提示(3 秒) > 加载中 > 文件未找到 > 加载失败 > 幻灯片播放中 | 总是 |
| 预加载中 | 后台预载指示 | 预载时 |
| POS: x,y | 鼠标处源图坐标 | 像素信息开关开 |
| RGB: r,g,b | 该像素颜色 | 同上（图外时不得输出脏数据） |
| 帧号 n/总帧 | 动图帧位置（可配"剩余帧"形式） | 动图 |
| 尺寸段 | 宽 x 高 (文件大小 KB，千分位) | 有图 |

### 10.6 标题栏文字格式（三选一）
完整路径 / 仅文件名（默认）/ 不显示。

### 10.7 对话框清单
选项（左侧树 + 三个页：常规/视图/控件）、自定义幻灯片间隔（毫秒/秒/分钟）、Everything 搜索（关键词 + 随机化复选）、编辑快捷键、跳到、重命名、关于、打开文件、文件夹浏览。
所有对话框文本运行时从语言表注入（rc 模板中的文字仅占位）。

### 10.8 工具栏（可选显示，默认隐藏）

- 位于窗口顶部的一排小按钮（工具栏控件），仅在"显示控件"开启时创建；默认沉浸模式不创建。
- 按钮序列（从左到右，即真实顺序）：**上一张 │ 下一张 │ 播放幻灯片 / 暂停幻灯片 │ 最佳适应 │ 1:1**。
- 每枚按钮有本地化文字提示；图标从资源装入（16px 基准，随 DPI 缩放）；悬停有提示气泡。
- RTL（阿拉伯语）时整条工具栏镜像反转；切语言时销毁重建（文字提示随语言更新）。
- 工具栏下方为可隐藏的窄条（rebar 容器），随控件一并显隐。

## 11. 多语言（i18n）

- 10 种语言：简体中文、English、日本語、한국어、Français、Deutsch、Español、Português、Italiano、العربية。
- 首次启动按系统界面语言自动选择（按主语言码匹配），不支持则回退英语。
- **切换语言即时生效**（不重启）：重建整个菜单栏 + 刷新标题/状态栏/勾选态 + 销毁重建工具栏；对话框每次打开时注入文本，天然即时。
- 阿拉伯语启用 **RTL 镜像布局**（窗口扩展样式加 RTL 布局标志，切换时动态加/去并全量重绘）。
- 字符串以**整数 ID** 索引；每种语言一张按 ID 排列的 UTF-8 字符串表（编译进 exe）；取词函数带越界防护。分隔线用特殊 ID(-1)。

## 12. 配置系统

- 单文件 `voidImageViewer.ini`，唯一节，UTF-8，自研轻量解析器。
- 位置：优先 exe 同目录（便携）；该文件中的 `appdata=1` 时改存 `%APPDATA%\程序名\`（该开关本身只能写在根 ini）。
- 保存：程序退出、系统注销/关机、选项确定、切语言、安装器参数时；**先写临时文件再原子替换**，防写坏。
- 完整配置键见附录 A。

## 13. 单实例与命令行

### 13.1 单实例
- 默认禁止多实例：第二个实例启动时检测命名互斥体 → 找到已有窗口（重试若干次防时序问题）→ 把自己的命令行/工作目录/显示方式打包经 WM_COPYDATA 转交 → 退出。
- 首实例收到后：切换工作目录、处理命令行、恢复窗口显示。
- 短时间内连续投递命令行视为"追加"而非"替换"播放列表（时间窗可配，默认 500ms）。
- `multiple_instances=1` 允许并行多实例。

## 14. 文件关联（安装器与选项对话框共用）

- 全部写入 **HKCU\SOFTWARE\Classes**（用户级，无需管理员）：
  1. 每个扩展名建专属 ProgID 键：默认值=本地化描述、DefaultIcon=程序图标、open 命令=`"程序路径" "%1"`（.ico 特殊：用文件自身图标）；
  2. 在 `.扩展名` 键下记录原默认值到备份值，再指向 ProgID。
- 卸载时从备份恢复原值并**整棵删除** ProgID 键（必须能删带子键的树）。
- 检测逻辑同时校验两处值一致才算已关联。

## 15. 错误处理与健壮性要求（验收红线）

1. 任何解码失败都要有"加载失败/文件未找到"提示，不得显示空白当成功；
2. 帧延时为 0/缺失不得死循环或崩溃；
3. 外部数据（Everything 回执、EXIF、延时属性）全部边界校验后使用；
4. 恶意超大图（乘法溢出、>2GB 文件）拒绝加载；
5. 退出时干净终止加载线程（原子标志 + 等待退出）；
6. 程序崩溃级 bug 不得出现在：随机模式删图、加载中翻帧、像素读取越界。
